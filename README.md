* Hakamlik va baholash jarayonida loyihaning to'liq imkoniyatlarini ko'rish uchun aynan o'sha fayl ichidagi havolaga o'tishingizni so'raymiz.

## 🛠 Loyiha haqida (Lokal kod strukturasi)

Lokal kod yozish jarayonida quyidagi texnologiyalar va prinsiplar asosida poydevor qo'yildi:
* **Language:** Kotlin
* **Architecture:** Jetpack Compose, Multi-module architecture
* **UI Framework:** Compose

Loyiha arxitekturasi va kod yozish uslubimizni baholash uchun ushbu repozitoriy kodi bilan ham tanishib chiqishingiz mumkin.
